# 🌐 Personal Portfolio Website
This is a personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. It showcases my skills, projects, resume, and contact information in a simple, responsive layout.

# 📁 Features
- ✅ Responsive Design for Mobile and Desktop
- 🧑‍💻 About Me Section
- 📂 Projects Showcase with links
- 📧 Contact Form (non-functional or functional via service like Formspree)
- 📄 Resume Download

# 🛠️ Tech Stack
- **HTML5** – Structure and layout
- **CSS3** – Styling and animations
- **JavaScript** – Interactivity and DOM manipulation
